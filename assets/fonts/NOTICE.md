# Bundled fonts

- **GurbaniAkhar** (True / Thick / Heavy) - the community-standard Gurmukhi
  typeface for Gurbani, by Dr. Kulbir Singh Thind, distributed via the ShabadOS
  / SikhiToTheMax project for free Gurbani use. Default shabad font.
- **Noto Sans Gurmukhi** - Google Noto, SIL Open Font License 1.1. Alternate /
  fallback (clean OFL).

GurbaniAkhar's redistribution terms are those under which STTM (public) ships it.
Verify attribution before a public release.
